To create a custom Certificate Authority (CA) and configure Ubuntu to trust it system-wide, you must generate the root keys using OpenSSL, 
copy the certificate to the local share directory, and execute the update utility.

Here is the exact step-by-step procedure to generate and install your own CA certificate on Ubuntu.

1. Generate the CA Root CertificateRun the following OpenSSL command to generate a private key and a self-signed root certificate at the same time:
bash

openssl req -x509 -sha256 -days 1825 -newkey rsa:2048 -keyout myCA.key -out myCA.crt


Follow the interactive prompts to define your country, organization, 
and common name

.Secure the resulting .key file; it grants the ability to sign certificates for any domain.

2. Copy to the Local Trust Store

Move the generated public certificate (.crt) file into the local administrator directory. The filename extension must be exactly .crt or the update utility will skip it.

bash

sudo cp myCA.crt /usr/local/share/ca-certificates/myCA.crt

3. Update the System Certificates

Run the update utility to rebuild the system bundle found in /etc/ssl/certs/ca-certificates.crt:

bash

sudo update-ca-certificates

The terminal will output confirmation text showing that the certificate count increased by one.

4. Verify Installation

Ensure a symlink was successfully created in the active certificates directory:

bash

ls /etc/ssl/certs/ | grep myCA

Handling Application-Specific Certificate Stores

While update-ca-certificates configures standard system tools like curl and wget, specific runtimes require environment overrides to acknowledge your new root CA:

Node.js: Provide the absolute path to your file by setting the NODE_EXTRA_CA_CERTS environment variable before launching your process.

Python: Force libraries using the certifi package to read the system-wide store by exporting REQUESTS_CA_BUNDLE=/etc/ssl/certs/ca-certificates.crt.

Browsers (Firefox/Chrome): You must manually import myCA.crt through your browser's security/privacy settings panel.

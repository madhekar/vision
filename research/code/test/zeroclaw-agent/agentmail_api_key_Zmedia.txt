An OpenClaw Himalaya skill showing as "unavailable" typically means the underlying CLI binary is missing, the exec tool permissions are restricted, or the configuration path is invalid.Fixing the Himalaya Binary and PermissionsVerify CLI Installation: Confirm that the himalaya email client is installed and accessible in your system terminal by running himalaya --version.Enable Exec Tool: Ensure your OpenClaw configuration allows execution permissions, as the skill relies on shell command access. Set tools.exec.security to full and ask to off if commands are hanging or blocked.Check Config Path: Verify your IMAP/SMTP settings file exists properly at ~/.config/himalaya/config.toml.Restart Gateway: Run openclaw gateway restart to clear cache and force OpenClaw to rescan the bundled and workspace skill directories.

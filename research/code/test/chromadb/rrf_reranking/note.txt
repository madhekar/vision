Stage 1: Candidate GenerationThe input image is fed into your base vision-language model (e.g., LLaVA, BLIP-2, or Qwen-VL) to generate a diverse set of N candidate captions (typically N = 5 to 20). This is done using diverse beam search or temperature sampling to ensure the model outputs different focal points and structural styles.Stage 2: Reranking Strategies (How to Score)You can rank your generated captions by choosing one or a hybrid combination of the following modern reranking methods:Multimodal Cross-Encoders (Vision-Text Rerankers):How it works: Instead of evaluating the text alone, you pass the original image and a candidate caption simultaneously into a vision-text cross-encoder.Examples: Models like NVIDIA's Llama Nemotron Rerank VL act as powerful multimodal cross-encoders. They directly output a matching score by forcing deep cross-attention layers to correlate specific image patches with descriptive words.
